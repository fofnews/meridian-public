## Task 3: tab-scroll flag that can go stale (`OpenStory.jsx`)

`queueTabScroll` only ever sets `pendingTabScroll.current = true`. Tapping the tab that's already selected while the tab row is pinned sets the flag, but React skips the re-render, so the flag stays set. The next tab change then scrolls even if the row isn't pinned.

- Assign instead: `pendingTabScroll.current = isPhone && !!tabRowRef.current && Math.abs(top - stickyH) <= 20`.
- Also skip queueing when the tapped tab, or picked thread, is already selected.

Check on a production build (`npm run build && npx vite preview`; the dev server's StrictMode runs effects twice), at 375×812:
- Pin the tab row, tap the selected tab, scroll up so the row unpins, tap another tab: no scroll.
- Pinned switching Facts → Disagreements → Headlines still lands each panel right under the tab row.
